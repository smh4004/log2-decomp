# ROM map: Dragon Ball Z: The Legacy of Goku II (USA), ALFE

8 MB (0x800000 bytes), SHA-1 `18e0715dec419f3501c301511530d2edcd590f8b`.
Offsets are ROM file offsets; add 0x08000000 for the bus address.
The byte-level classification (100% coverage, 6,327 ranges) is `config/regions.yaml`, generated by `tools/bfdis/regions.py`.
Layout constants used by every tool are in `config/game.json` (read by `tools/bfdis/game.py`) and `tools/assets/const.py`.
